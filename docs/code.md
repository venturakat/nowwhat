# Now what? — code reference

How the app is built. Workflow, pushing and rules: `CLAUDE.md`. History: `git log` (commit messages describe each feature).

## Stack
Vite 5 + React 18 + TypeScript, zustand store persisted to IndexedDB (idb-keyval), vite-plugin-pwa. Versioned migrations in `src/store.ts` (`migrate()`, v12; `src/seed.ts` version must match) plus unconditional shape fixes at its end (old `lessons` → `classes`, weekly class paying → monthly, `migrateCleanPlan`, `fillCurs`, `markTaxSince`). `useSt()` = whole state (no selector); for a slice use `useStore((z) => z.st.…)`; `update(d => …)` to change data.

## Type and font
Commissioner (`@fontsource/commissioner` 400/500/600/700 in main.tsx) for every language (Afacad has no Cyrillic). Type scale: body 15, .sub/.t15 13, .t14 12.5, .t13 11.5, tab labels 10.5, .h1 38.5, .big 56.5, .mid 26.5; hero `fitSize` sizes e.g. Today 63.5, Budget 46. Form fields stay ≥16px (`.input` 16px + global `input, select, textarea { font-size: max(16px, 1em) }`) or iOS zooms on focus.

## Languages
English, Ukrainian, Russian, Spanish (Rioplatense/voseo, shown as plain «Español» — if European Spanish is added, split into two labelled chips).
- `src/i18n.ts`: `tr(en, vars?)` (`{x}` placeholders), `trn(n, one, other, vars?)` (dict key `'one|other'` → value `'one|few|many'` via Intl.PluralRules; Spanish stores `'one|other|other'`), `monthNames(long)` / `weekdayNames(long)` (lib's `fmtDay`, `fmtWeekday`, `monthName`, `weekdayName` use them; `curName` uses the app language), `getLang`, `resolveLang`.
- Dictionaries `src/i18n/uk.ts`, `ru.ts`, `es.ts` keyed by the English text, all with the SAME keys — every new UI string needs an entry in all three. uk.ts uses single quotes, ru/es double; several keys per line — check keys by node-evaluating the object (slice from the `{` after `Record<string, string>`), not by regex; the last entry sits before the final `}`. New language the quick way: node-eval ru.ts → `keys.json`, write `<index>\t<translation>` lines (plurals `one|other`, `\n` for newlines), a build script checks count, placeholders and plural parts.
- Style: informal «ти»/«ты»/vos, non-gendered forms («Своїми силами»/«Своими силами»/«Por mi cuenta», «Приготовано», «Куплено», «вдягнуто 3×»/«надето 3×»/«usado 3×»); short months with dots ("7 лист.", "7 нояб.", "7 nov.", Russian May «мая»), long months lowercase nominative ("листопад"/"ноябрь"/"noviembre", also mid-sentence).
- Her word choices: Outfits «Аутфіти»/«Аутфиты», Parking lot «Парковка справ»/«Парковка дел», Wardrobe header «Мої речі»/«Мои вещи». Spanish (my picks, she may change): voseo imperatives (agregá, tocá, guardá), «celu», Money «Plata», Supplies «Provisiones», Home «Casa», Closet «Placard», Meds «Remedios», Groceries «Súper», Outfits «Looks», Wardrobe «Mi ropa», Parking lot «Pendientes», Brain dump «Notas», Shipment log «Envíos», fortnight «quincena», Light/Regular/Extra clean «rápida/normal/a fondo», Stove «Hornalla», Aerogrill «Freidora de aire», rate «cotización», tax rate «Alícuota», tax lines «Pagos».
- `settings.lang` = 'en' | 'uk' | 'ru' | 'es', or unset → `resolveLang` takes the first `navigator.languages` entry starting with uk/ru/es, else English. Settings › Language (first card): chips English / Українська / Русский / Español, the one in use highlighted. Erase everything keeps the language.
- Switching language re-renders in place: a store subscription calls `setLang`; App subscribes to the language; open sheets (elements kept in `useUi`) go through `refresh()` in App.tsx — a deep `cloneElement` of each sheet and elements in its props — in a `useMemo` keyed on `[under, sheet, lang]`. Don't bring back `<Fragment key={lang}>` (rebuilt everything, replayed the sheet animation). Keep `tr()` calls inside render (module-level constants / `useMemo` without `lang` won't update).
- Primitives translate plain string props themselves: `Header` sub/title, `Chips` labels, `List` title/right/empty, `Field` label, `Sheet` title, `FormSheet` labels/options/placeholders/saveLabel, toasts. NOT translated: `Row` title/meta, FormSheet `suggest` pills (pass `.map((x) => tr(x))`), the Budget `Fold` title is translated inside `Fold`.
- Avoid keys that need different translations in different places: "Light activity" (cleaning uses "Light"), `tr('Home supplies')` for the Supplies Home list (via `catItems()`), 'Period (cycle)' via `perWord()` (tax 'Period' differs), 'Name (person)', 'Clear (weather)' — English keeps the plain word via `getLang() === 'en'`; language checks are `getLang() !== 'en'`.
- Money words: fortnight «два тижні»/«две недели»/«quincena»; `ord(n)` (Subscriptions.tsx) gives "5-го" in uk/ru, plain number in es ("el 5 de cada mes"); keys like '{d} of the month' → '{d} числа'; `fmtHours` unit `tr('h')`; quarters `tr('Q{q} {y}')` = «4 кв. 2026»/«T4 2026»; lib `relDays` translated.
- Stored-in-English, shown via `tr`: starter cleaning step names (own steps show as typed; editing a starter step pre-fills the translation), `TRAVEL_STARTER` travel necessities, closet kinds (`CATS`, `CAT1`), weather place "Where I am" (`placeName(p)`); city search asks Open-Meteo in the app language.
- Still English on purpose: the app name "now what", copied invoice lines "Total:", default timer task name "Work". Known gap: season names in 'Done this {s} on {d}' / 'Not done this {s} yet' are passed in English (es shows «esta autumn»).

## Shared UI (ui.tsx, form.tsx)
- Navigation: tabs Today · Money · Supplies · Home · Closet. Sideways swipe walks every sub-tab and carries into the neighbouring tab (`registerSubs`, `nextSpot`; swipe.ts ignores edges, sheets, sideways-scrolling rows). On Supplies the dock's own button becomes "Add new" (plus icon) and opens `SupplyEdit` for the open sub-tab (`addSupply`); no Add buttons under supply lists.
- `Header`: gear on every tab (`registerSettings`) with today's date (`fmtWeekday(today())`) left of it — `.hdr-right`, absolutely placed top-right on the sub line. Today's sub line = "Your daily hub app". The Calendar passes its own `right`.
- `List`: `.list` padding 14/6 for cards with a header; without `title` → `.list.bare` (6px top and bottom).
- Sheets: `openSheet` / `pushSheet` / `popSheet` stack; pages under the top one stay mounted (App renders `[...under, sheet]` as one keyed list via refreshed `pages`). Slide-in only right after a push (`useUi.pushed` → `.page.pushed.slide`). Focused fields scroll above the keyboard (`keepInView`). Max height follows the visual viewport (`useVisibleArea`); `.kb-fill` continues the sheet background behind the keyboard. Pull down closes. A pushed page keeps the sheet at least as tall as the page it covers (`minH`). `Sheet` takes `title: ReactNode`, `actions` (replace the close cross), `full`. `closeSheet` closes the whole stack. Settings sub-page from elsewhere: `openSettings(); pushSheet(<XSheet />)` (`BackupSheet`, `CurrenciesSheet`, `TaxesSheet` from settings.tsx).
- `FormSheet`: text fields take `suggest: string[]` (pills that fill the input; tap again to clear), `off(v)` (greyed), `hide(v)`; `twoTap` = two-tap Delete; with `onBack`, Save and Delete go back one page; `full={false}` keeps a pushed form normal height; `onDelete` returning `false` keeps the form open.
- `DragList` (`ids`, `onMove(from, to)`, children `(id, grip) => row`): six-dot grip (`.noswipe`, `touch-action: none`, pointer events), lifted row shadow, reorder on release. Use for any reorderable list.
- Hero amounts: `fitSize(text, size, fit)` (lib) — full size up to `fit` characters, then shrink (min half).
- Two-tap destructive buttons: first tap arms for 3 s (red stroke + red text, label "Delete"), second deletes; no toast. Bin icons in rows work the same.
- Sideways-scrolling rows hide the scrollbar (`.chips`, `.hscroll`, `.catrow`), otherwise iOS shows a white bar.
- `copyText(text, toastMsg)` exported from Money.tsx.

## Currencies (v9)
`settings.mainCur` (totals/budget; mirrored in lib's `MAIN` so `fmt()` works anywhere), `settings.curs` (others in pickers — `curOptions(s, keep)`), `settings.rates` (main per 1 unit, today), `rateSrc` per currency: `market` (open.er-api.com, Frankfurter fallback), `official` (`OFFICIAL` in rates.ts: NBP tables A+B for PLN, NBU for UAH, dolarapi/Banco Nación for ARS), `blue` (dólar blue, only where `blueFits(main, c)`: ARS when main isn't ARS, USD when main is ARS), `manual`; `rateNote`; `rateLog` by day `{m, r}` — `rateOf(s, cur, date)` uses it for past dates (past amounts frozen; before the log = its first day). Helpers `toMain`, `conv`, `fmtCur`, `fmtBoth`, `usedCurs` (codes in data — rates fetched for these), `fillCurs` (every `update()`: amounts without currency get the main one). Add-currency picker = `allCurrencies()` = hard-coded `ACTIVE` ISO 4217 codes in use in 2026 (BGN dropped, ANG→XCG, ZWL→ZWG, SLL→SLE), whole list. `switchMain` (settings.tsx) inverts rates, old main → others, resets sources that no longer fit, converts plain-number prices (supplies, project costs, needs maxPrice). Taxes in `settings.taxCur` (default PLN; `fmtTax`, `sessionTax`); sessions `sessionCur/sessionAmt/sessionMain`, `Client.cur`, `nbpRate` (`nbpRateForInvoice(date, cur)`, only when the tax rule is `nbp` and taxCur is PLN — `needsRate(st, s)`). `CoursePay.plnCur` = currency of `pln`. Numbers are formatted by the phone's region (`toLocaleString(undefined…)`), whatever the app language.

## Taxes (v10; lib.ts tax section + src/taxes.ts)
- `settings.taxLines: TaxLine[]` {id, name, kind `fixed` | `pct` | `pctLess` (pct × (revenue − lessPct% of line `less`)), amount, pct, every month/quarter/year, payDay, dueDay, group?}. `lag` (`lagOf`, default 1) = paid this many months after its period ends (0 Monotributo, 2 Ukraine single tax). State in `taxMonths[<period's last month>].lines[id] = {paid?, amount?}`; `revenueOverride` per month; quarterly revenue = sum of its months (`monthRevenue`).
- `taxPeriod(st, endMonth)` = maths for periods ending that month (TaxMonthSheet, estimates); `taxFor(st, payMonth)` = everything paid that month → {month, revenue, parts (carry `end`), groups (by `group` or id: one tile + one Paid button), total, left, paid}; `lineAmounts`; `taxPays(st, payMonth, tx?)` = payments grouped by pay day (budget auto lines, calendar, Today); `periodLabel`/`partsName`, `taxLeftName`, `setTaxPaid(d, mk, groupKey|'all', on)`, `dayOf`.
- `settings.taxSince` (YYYY-MM, first month a line had an amount or %; `markTaxSince` in every `update()`); `taxFrom(st)` = first month of taxSince's year with revenue, else taxSince; `taxForBudget(st, pm)` = taxFor without parts ending before taxFrom — only the Budget uses it.
- `settings.taxRule`: `nbp` / `invoice` / `paid` (cash basis by `paidDate`). `settings.transfer: {id,label,text}[]` with `fillTransfer` placeholders `{month} {miesiąc} {місяць} {mes} {mm} {yyyy}`. Default pay day = deadline − 5 (`defaultPayDay`, `PAY_BEFORE`) — no hard-coded 1st. Presets `PRESETS` (pl `dra`/`rca`/`pit`, ua, ar, custom), `applyPreset`, `migrateTaxes`. Settings › Taxes = `TaxesSheet` (Start from — two-tap, second tap "Switch"; Taxes are in; Invoices count; Tax lines → `TaxLineSheet`; Transfer details → `TransferRowSheet`). Old fields (`dra`, `rca`, `pitRate`, `taxPayDay`, `taxDueDay`, `zusAccount`, `taxAccount`, `zusBasis`, `nip`/`regon`/`pesel`, `taxIdKind`) stay in data, unused. ZUS, liniowy/skala and budget tax estimates: see `git log` for `taxes`/`ZUS` commits.

## Money
- Sub-tabs: Budget, Work, Taxes, Selfcare, Classes, Subscriptions, Credits, Savings.
- Budget (Money.tsx `Budget`): Left card (doesn't fold; bar includes saved; "Spent X of Y · Z to savings"; "Move to savings", dated today or the half's end when viewing another half) · Came in (incl. "From savings" rows, tap → `AccountSheet`) · Expected income in budget · Expected income not in budget · Mandatory planned · Mandatory paid (only when not empty) · Supplies bought · Moved to savings (only moves into savings) · Day-to-day spending (+ `MergeSpends` footer: same what-for + currency, two taps → one spend dated the merge day) · "+ Log spending" (`SpendSheet`, what-for pills Eat out, Delivery, Taxi, Coffee, Movies, Books, Gifts, Travel).
- Every Budget block is a `Fold` (`id`, `open` default; tap the title to fold/unfold): state in `settings.folds[id]` (true open / false folded; kept on the phone and in backups). Ids: in, exp-in, exp-out, planned, paid (start open), bought, saved, spent (start folded).
- Expected income (lib `autoLines`, `AutoLine.expected`; `counted` = in Left): "in budget" = monthly-fee sessions, counted in the half of their fee date even before paid, never moved, plus manual Money in lines that repeat every month dated after today (Money.tsx `upcoming`; display only — they're in Left either way; on their date they show in Came in; tap → edit); "not in budget" = hours (per client + invoice, or per client when not invoiced) and per-job fees, meta "invoiced"/"not invoiced", not in Left; anything before the current half still unpaid moves to the current half (`curStart`/`inHalf`; past halves no longer show it). Paid → a `fromClient` Came in line dated the paid day.
- Came in: its total = only its own rows (non-expected auto income + Money in lines shown there + From savings), not `s.income` (the Left card's "Spent X of Y" still uses `s.income`). Client payments (`fromClient`) always show "business revenue", no revenue toggle in their form (manual Money in keeps it). Tax revenue from budget items via `incomeIsRevenue`: a `fromSession` line counts only if its session has no invoice date; others by `taxable`.
- Paid = `AutoLine.paid` (tax groups marked paid, subscriptions whose day < today, credit payments whose date < today — `credits-paid` vs `credits`, one summed line each, an overdue selfcare time) or `isPaid(item)` = `item.paid ?? item.oneOff` (manual expenses have a "Paid" switch; template copies drop `paid`).
- Repeating lines (v12): manual Money in / Mandatory expense have "Repeat every month" (`BudgetItem.repeat`, default No). An unopened half (`periodItems`) copies only `repeat` lines from the same half of the latest earlier month (`repeatCopy`: id `<series>@<key>`, `seriesOf(id)`, same day clamped; `paid` dropped). Switching on also copies into existing later halves of the same type; off removes later copies. Meta "every month". Deleting one pushes `DeleteRepeat` ("Just this one" — first `ensurePeriod`s next month's same half so the series carries on — / "This and all months after"). Edits don't spread.
- Work: client sheet `<Sheet title={c.name} full>`; job / hours / fee rows and "+ Add …" push `SessionEdit` (`onBack={popSheet}`) so Save/Delete/Back return to the client. Monthly-fee clients (`kind: 'fixed'`): `ensureFees` makes one session per month (`feeMonth`). Skip a month = set that fee to 0: `isSkipped(s)` → meta "skipped", grey `C.line` dot, out of "Not invoiced yet" (client sheet, Work list, Today reminder) and of expected income; `ensureFees` keeps 0; fee form hint "Amount 0 = this month is skipped."
- Selfcare: idea chips `IDEAS` (Manicure, Pedicure, Massage, Haircut, Esthetician, Doctor — sport belongs in Classes); Delete two-tap.
- Classes (`src/screens/Classes.tsx`, `State.classes: Course[]`): price + currency and Payment currency (`payIn`), pickers = Settings › Currencies + the class's current one. Rate when they differ: "Today's rate" (`app`, source from Settings › Currencies) or "I type it when paying" (`manual`); old `blue`/`oficial` read as `app` (`classRateKind`). Fee + fee currency, days, time. `payEvery` 'class' | 'month' (default month; weekly dropped):
  - Per month: `payDay` (only the day stored); card "next payment · Month", tap amount to copy, "Paid" → PaySheet logs a budget item; calendar "Pay for…" event and Today reminder (3 days before) on the `classBatch` due date. Budget: the batch on its due date and every later month (`classBatch(st, c, t, month)` = that month's unpaid classes, price × classes + fee, today's rates); earlier months nothing. When this month is paid and the card has moved on to a later month, a "<class> in <this month>" list between the card and the next month's list (`PaidAhead`) shows this month's paid classes from today on (time · paid).
  - Per class (`paysPerClass`): one budget line per class per fortnight (price + fee each time, converted per date). Card "cost this month" (`classMonthCost`), no Paid button, Payments row hidden unless old payments exist; no calendar payment event or Today reminder.
- Credits: extra/closing payments log in the credit's currency.
- Savings (`src/screens/Savings.tsx`, `State.savings?: SavingsAccount[]` {id, name, currency, goal?, note?, moves}): total = sum of moves (`accTotal`); a move = {date, amount in the account's currency (negative = out), note?, budget? + budgetCur (taken from the fortnight when positive, given back when negative, in the main currency of the time)}. `summarize` adds `saved` (positive budget parts in the half, out of Left) and `fromSavings` (negative flipped, added to `income`, not taxable); Left = income − fixed − spent − saved. Moves without `budget` don't show in the Budget. Moves between accounts are linked, converted at the date's rate; editing or deleting one side updates the other. Editing an account's currency converts its amounts and goal at today's rate after a red second-tap warning. The budget switch can be turned on/off on existing records. Exports `AccountSheet`, `AccountEdit`, `MoveToSavings`.
